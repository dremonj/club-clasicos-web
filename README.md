# Club Clásicos Cierzo

Maqueta de página web para una asociación de coches clásicos españoles (Zaragoza).
Tiene dos secciones: **El club** y **Eventos y rutas**. Es una página estática: no necesita servidor ni inicio de sesión.

Nombres, fechas y datos son de ejemplo. Fotografías: Wikimedia Commons (licencias Creative Commons).
